# StudyPlanner – University Study Planner

## Project Description

StudyPlanner is a web application designed to help university students organize their academic tasks, assignments, and deadlines in one place. Students can manage their activities, track their progress, and plan their study time more effectively.

## Main Features

- Task Management: Create, view, edit, and delete academic tasks.
- Deadline Tracking: Set due dates for assignments and projects.
- Progress Tracking: Mark tasks as pending or completed.
- User Authentication: Create an account and log in to manage personal tasks.
- Dashboard: View pending tasks, completed activities, and upcoming deadlines.
